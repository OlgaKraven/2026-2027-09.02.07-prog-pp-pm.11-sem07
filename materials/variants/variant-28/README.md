# Исходные материалы: Магазин одежды для поваров

Это исходная БД и данные варианта 28 учебной практики ПМ.11. Сохранены исходные товары, размеры, клиенты и история. Для производственной используйте свою копию или восстановите baseline.sql в новую пустую pp11_v28. Исходный набор: 5 моделей, 2 размера, 10 размерных позиций, 2 клиента, 1 заказ, 1 строка заказа; историческая сумма указана в data/context.json. Затем примените общие миграции по методичке: добавятся 3 учебных пользователя разных ролей. Встроенных решений дополнительных условий здесь нет.

Логины исходных клиентов: client, buyer. После миграции доступны pp_client, pp_manager, pp_admin. Для своего приложения измените Company, Database и имена четырёх подключений СУБД; названия размеров возьмите из своего sizes.csv. Если изображения отсутствуют, используйте общую заглушку.
