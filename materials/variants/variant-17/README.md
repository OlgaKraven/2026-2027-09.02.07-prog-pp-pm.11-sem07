# Исходные материалы: Магазин одежды для собак

Это исходная БД и данные варианта 17 учебной практики ПМ.11. Сохранены идентификаторы, размеры, клиенты, остатки и история; названия и категории товаров уточнены для содержательной проверки фильтра. Если продолжаете свою БД учебной практики, после резервного копирования выполните classification-fix.sql этого варианта и проверьте выведенный каталог. Для нового импорта baseline.sql эта правка уже включена. Для производственной используйте свою копию или восстановите baseline.sql в новую пустую pp11_v17. Исходный набор: 5 моделей, 2 размера, 10 размерных позиций, 2 клиента, 1 заказ, 1 строка заказа; историческая сумма указана в data/context.json. Затем примените общие миграции по методичке: добавятся 3 учебных пользователя разных ролей. Встроенных решений дополнительных условий здесь нет.

Логины исходных клиентов: client, buyer. После миграции доступны pp_client, pp_manager, pp_admin. Для своего приложения измените Company, Database и имена четырёх подключений СУБД; названия размеров возьмите из своего sizes.csv. Если изображения отсутствуют, используйте общую заглушку.
