# Исходная база магазина «Пара»

Используйте собственную БД учебной практики либо создайте новую пустую pp11_demo и импортируйте baseline.sql через phpMyAdmin. До миграции: 31 модель, 35 размеров, 92 позиции, 20 пользователей, 10 заказов, 30 строк заказов; сумма остатков 1274, сумма исторических заказов 341770.00. Это исходная точка, а не результат производственной практики. Затем применяйте миграции по методичке. CSV в data нужны для сопоставления с учебной практикой, повторный импорт в заполненную базу не требуется. Изображения в data/Images используются приложением; заготовка уже содержит их копии в Assets/Images.
