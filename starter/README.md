# Основа приложения своей предметной области

Открыть ShopDb.csproj после подготовки рабочей БД по методике. Вход, чтение каталога, отбор и календарная цена предоставлены готовыми. Точки самостоятельной работы Repository и корзины обозначены в коде. Их заполнение и проверки объяснены в основном маршруте и подробном справочнике. settings.local.json создать из settings.example.json; в Git он не включается.
