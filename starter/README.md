# Заготовка ShopDb

Откройте starter/ShopDb.csproj в Visual Studio 2026 с компонентом .NET 10 и WPF. Заготовка содержит пустое окно, ресурсы и ссылку на MySqlConnector 2.5.0. Разработка каталога, запросов и заказов выполняется по методичке. Скопируйте settings.example.json в settings.local.json и задайте свои параметры после создания БД и учётных записей. Сборка: меню Сборка → Собрать решение; запуск: Ctrl+F5. Не открывайте демонстрационное решение вместо заготовки до самостоятельной реализации.

Локальные параметры, пароли и каталоги bin/obj не публикуйте. Ресурсы логотипа, иконки и заглушки перенесены из исходного комплекта магазина «Пара» без изменения изображений. Для областей без изображения товара используется заглушка.
