# Сборка учебного комплекта

Содержание хранится в `content/course.json`. Основной маршрут, подробный справочник и предметные области различаются ключами `guide`, `reference` и `areas`. Учебные данные вариантов находятся в `materials/variants/`; не заменять их демонстрационными данными.

Для сборки необходимы Python 3, python-docx, ReportLab, Pillow и fontTools. Современное оформление обоих PDF задаёт `tools/pdf_layout.py`: Golos Text, тёмные шапки, круглые номера и серые скруглённые блоки. Для этих учебных PDF применяется согласованный визуальный эталон; форма отчёта DOCX сохраняет свой профиль оформления. Переменная `PP11_MONO_FONT` задаёт моноширинный TTF для кода; по умолчанию используется Windows Consolas. `PP11_FONT_DIR` задаёт каталог Golos Text и его лицензии. Шрифт и лицензия хранятся в `site/assets/fonts/`; можно также использовать ресурсы персонального навыка предметных областей.

1. При изменении формы выполнить `python tools/export_report.py`. Открыть DOCX в Word, обновить содержание и номера страниц, проверить его отрисовку. Сохранённый файл в `forms/` является итоговой редактируемой формой; повторный вызов экспортёра создаёт её заново.
2. Выполнить `python tools/build.py`. Сборщик обновляет HTML, архивы, оба PDF и manifest. `assignment.pdf` содержит методические рекомендации, `guide.pdf` — предметные области; это соответствует именованию вложений EatDoners.
3. Отрисовать и осмотреть PDF, проверить оглавление, закладки, переносы, ссылки и архивы. В обоих PDF должны сохраняться прямые ссылки на исходный комплект и демонстрацию.
4. При изменении кода собрать `app/ShopDb.csproj` и `starter/ShopDb.csproj`. Пустые точки доработки в starter намеренные; готовые вход, отбор и чтение сохраняются.

В PDF длинные листинги переносятся для чтения и разбиваются на подписанные части. Исполняемые файлы находятся в скачиваемом архиве. SQL выполнять целиком только после окончания соответствующего объекта; команды проверки не оборачивать во внешний ROLLBACK, если процедура сама выполняет COMMIT.

Проверочные базы, локальные настройки, пароли, сборки и результаты аудита в учебный репозиторий не включаются. Служебные отчёты и доказательства находятся отдельно в BrainM.
