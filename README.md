# Производственная практика ПМ.11

Разработка, администрирование и защита баз данных. 4 курс, 7 семестр, 2026–2027 учебный год. C# WPF, MySQL в XAMPP.

[Открыть учебный сайт](https://olgakraven.github.io/2026-2027-09.02.07-prog-pp-pm.11-sem07/).

Комплект продолжает учебную практику ПМ.11: разработка приложения для своей базы данных и предметной области, каталог и оформление заказа, роли клиента, менеджера и администратора, исторические цены, транзакции и восстановление. Учебный вход по логину используется только в демонстрации; подключения к СУБД имеют отдельные ограниченные права.

На сайте размещены подробная методичка с постепенным написанием кода и реальными снимками, 30 предметных областей, отдельный пример магазина «Пара», PDF задания и методички и общий шаблон отчёта Markdown. В каждом варианте повторяются прямые ссылки на заготовку WPF, SQL-доработки, собственные исходные данные и пример для сверки после самостоятельной работы.

При сдаче проекта приложите ссылку на его репозиторий.

Исходный учебный материал: КИМ 09.02.07-2-2027, том 1, задания 2–4; происхождение исходных данных и учебные дополнения объяснены в комплекте. Демонстрация фактически выполнена на Windows: MySQL/MariaDB в XAMPP, Visual Studio и WPF. Проверены все 30 БД вариантов, права, повторный запрос, откаты, исторические цены и восстановление. Код восстановлен по порциям методички с проверками промежуточных сборок.

Локальные настройки подключения и пароли не входят в публикацию. Перед запуском создайте свои учебные подключения по руководству; исходную БД дорабатывайте в отдельной копии.

Исходники: app/, starter/, database/ и materials/. Единый источник содержания: content/course.json. Выпуск: site/.
